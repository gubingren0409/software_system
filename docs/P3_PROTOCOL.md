## 预先声明的轨迹

每算法五个搜索种子 20261008--20261012，各 12 个不重复配置评估；预算 4/8 是同一
12 次轨迹的前缀，不另外运行或改变策略。完整目标是 120 次配置评估、720 次搜索
目标执行，独立复测另计（存在失败/中断时次数另记录）。

| 次序 | 算法 | 搜索种子 |
|---|---|---:|
| 00 | 无放回随机 | 20261008 |
| 01 | 随机重启贪心 | 20261008 |
| 02 | 随机重启贪心 | 20261009 |
| 03 | 无放回随机 | 20261009 |
| 04 | 无放回随机 | 20261010 |
| 05 | 随机重启贪心 | 20261010 |
| 06 | 随机重启贪心 | 20261011 |
| 07 | 无放回随机 | 20261011 |
| 08 | 无放回随机 | 20261012 |
| 09 | 随机重启贪心 | 20261012 |

此顺序在任何 P3 正式分数出现前确定。种子内算法次序交替，减少但不能消除时间段
混杂；各轨迹不共享性能样本。分批参数 trajectory-limit 只决定在哪条完整轨迹后
保存返回，不改变上述顺序、12 次预算或分数。默认本批先做 00/01；用户可选择持续
全部十条，未回复不阻塞实现和轻量回归。

无放回随机使用独立 Python Random 和 Fisher-Yates，取排列前缀。贪心每点最多
七个邻居：只改变一个参数到任意其他合法值（3 优化档+4 块大小）。先按自身 RNG
打乱未观测邻居并评估；邻居评估完成后仅接受严格改善，平分按规范配置顺序破同分。
无法改善时从未观测点随机重启；已观测邻居可参与决定，不再消耗预算。预算耗尽
立即返回自身最佳有效观测。精确定义和原实现均沿用 P2 search schema 2。

策略输入只有 ConfigSpace、种子和自身有序观测。运行器不读取 P2 Grid 或别的轨迹
的性能数据。检查点恢复重新创建 RNG，以本轨迹逐次 ask/tell 重放并核对顺序，不给
策略注入别的观测。全 campaign 基础构建和 reference 可以共享，性能不可共享。

## 独立复测和质量指标

在每条 12 次轨迹结束后，为其 4/8/12 前缀选出的不同候选各做一组独立预热+五次
测量；同轨迹同候选可以共用该复测组，跨轨迹不能共用。预计 10--30 组、60--180
次额外执行。复测不反馈给搜索、不更新原分数、不消耗唯一配置预算，失败停止该批
并记录，不能静默筛选或无限重试。

单独后处理程序在轨迹决定已保存后才读取完整 P2 表，并区分两类指标：

1. 选中配置在 P2 完整表中的质量差距：选中配置的 P2 中位数 / P2 表最低中位数 - 1。
   用于同一张表评价配置选择，不能作为策略观测或 P3 实测分数。
2. P3 自身测得时间相对 P2 最低时间的差距：两个 session 的实测比值，可以为负。
   不能据此宣称发现表外“真正最优”；环境漂移和未校准时钟可能改变这个值。

同时保存预算、最佳有效配置、各样本、独立复测、累计核心时间、配置接口墙钟、门禁
等待和活动会话成本。五种子完成后才评价跨种子稳定性；只有一个种子时标准差未知
（null），不能用 0 冒充稳定。Grid 完整 20 配置保持原表；若展示 4/8/12 前缀必须
注明 O0/O1/O2/O3 外层、s=8/16/24/64/128 内层的顺序偏置。

## 资源、暂停与身份

沿用 P2 正式启动门禁：Windows/WSL 可用内存各至少 2 GiB，WSL 根空闲至少 1 GiB，
宿主 CPU 五次采样平均≤10%、最大≤20%。setup 前及每配置/复测前均解析正式 JSON
和所有限值；退出码 0 或单独 PASS 字符串不够。拒绝则不新增目标运行，保存身份和
检查点，最多 16 次重新采集、每次间隔 30 s。期间记录资源快照、峰值 RSS、vmstat
及宿主压力，运行中不事后按资源筛样本。只运行一条目标；POSIX 文件锁排除重复 P3
运行器，不关闭用户应用或修改内核/电源/WSL 配额。

先提交运行内容，再 git archive 导出到 WSL 本地；移除 PYTHONPATH、禁用 pycache。
归档的 Git blob 与实际执行 SHA-256/换行形式分别记录；冻结内容 SHA、配置、源码、
编译器、二进制和 reference 数据身份。大缓存固定于
`/var/tmp/matrix-autotuner-p3-10245102457/cache`，不进 Git。

将 PAUSE_REQUEST 写入 campaign 根目录可请求安全暂停：当前目标返回后先落原始
样本与检查点，不启动下一次。显式 --resume 留存并清除该请求；已完成轨迹核验
全部原始记录和 checkpoint 哈希后恢复，部分组保留为 abandoned，重新完整预热
和五次测量。不得用一次性能缓存补五个样本。身份改变必须新建 campaign。

P2 已记录的 MONOTONIC/RAW/外部墙钟差异和宿主资源压力继续披露。门禁通过仅约束
启动时，不保证全程静止；尚无物理时钟校准、热/节流或硬件计数器因果验证。

## 验收与预算

受控目标测试唯一预算、失败无分数、RNG 重放、同分规范顺序、身份/完整性拒绝、
setup 门禁拒绝不构建不测量；从已提交归档另运行 CLI、单测、verify_p1、空缓存
n17 fresh、n130 全十条实际轨迹，以及真实部分组暂停/续跑。n130 全部仅诊断，
不得用来比较 n4096 性能。

按 P2 配置接口总墙钟 20088.175 s/20 外推，全部两算法五种子约 33.48 h 搜索，
每算法约 16.74 h；另加门禁、setup、失败、中断和候选复测。首种子两轨迹约 6.70 h
只是均摊条件估计，不保证配置组成和环境相同。先完成轻量验收，按实际完成速率与
配置组成更新剩余时间；不为了缩短时间改变冻结的五次测量或唯一预算。
