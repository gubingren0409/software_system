usage: prepare_raw_comparison.py [-h] --content-sha CONTENT_SHA --output
                                 OUTPUT [--mode {validation,search,both}]

Export an exact committed runner, verify it, initialize requested EMPTY
sessions. No clock collection, matrix target, reference generation or search
is performed. Run from the repository; all subsequent execution uses the
exported content.

options:
  -h, --help            show this help message and exit
  --content-sha CONTENT_SHA
  --output OUTPUT
  --mode {validation,search,both}
